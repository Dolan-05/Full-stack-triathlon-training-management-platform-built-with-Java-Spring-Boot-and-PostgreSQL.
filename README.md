# TriTrack

Full stack triathlon training management platform built using Java, Spring Boot and PostgreSQL.

## Current
-Athlete Management
-Rest API
-PostgreSQL database
-CRUD operations
-Input Validations
-Global exception handling
-Password Hashing using BCrypt
-API testing with postman

## Planned
-User authentication
-Workout logging
-Training calendar
-Performance analytics
-Nutrition guidance & strategy
-React frontend
-AWS deployment
-Garmin & Strava integration

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate

### Database
-PostgreSQL

### Tools
- Git
- Maven
- Intellij IDEA
- Postman

## Why I'm building it

TriTrack aims to solve the problem of unpredictable events clashing with triathlon training and derailing quality weeks, the long term goal is to build a platform that adapts in real time to whatever may try to get in the way of training, helping all athlete stay consistent.

This is my main software project that I'm designing to solve a personal problem of mine around training.
